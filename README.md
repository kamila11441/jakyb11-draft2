# Jakub Kowalski — Photographer Portfolio (@jakyb11)

A clean editorial photography portfolio starter customized for Jakub Kowalski / @jakyb11.

## Files
- `index.html` — site content and photo URLs
- `styles.css` — layout, typography, responsive styling
- `script.js` — category filters, mobile navigation, photo lightbox

## Run and publish
Open `index.html` in a browser, or use Live Server in VS Code.
To publish: upload the files to a GitHub repository, then choose **Settings → Pages → Deploy from a branch → main → /(root)**.

## Personalize
Replace demo Unsplash photos with Jakub's actual work. Update the short bio, project names, location, social links, and years in `index.html`. Main colors and spacing live at the top of `styles.css`.

The current site links the contact CTA to Instagram `@jakyb11` because no email address was provided. Add a business email if preferred. Demo images are remote and require an internet connection. Verify usage rights before publishing commercially.
